TALK / 01 · ISI BENGALURU MATH CLUB · EP2515

Fractional Dimension of the Cantor Set

Abstract

How can we measure a set of points that is somehow more than nothing but less than a line? The famous Cantor Set challenges our basic ideas of length and dimension. This talk will start from the very beginning. We will first explore why our usual concept of “length”, not only length but also “area” and “volume” fails for such similar type of complex sets and then motivate the need for a more powerful tool: measure theory. From there, we will build up the definition of the Hausdorff dimension, a concept that allows us to precisely quantify the “roughness” of shapes. Finally, we will apply this new tool to prove a beautiful and classic result: the dimension of the Cantor Set is exactly log 2 / log 3.

TALK / 02 · ISI KOLKATA MATH CLUB · EP2616

Beyond Integer dimensions: A Motivation Towards Fractal Geometry

Abstract

What does it mean for a set to have a dimension? Smooth curves are 1-dimensional, smooth surfaces are 2-dimensional and solids are 3-dimensional. But in the nineteenth and early twentieth century mathematicians discovered objects for which this intuition is no longer enough. We get to meet some of these “mathematical monsters”, including the Weierstrass function, the Cantor set and the Koch snowflake, and see why ordinary notions of length and size fail for them. Using the idea of scaling, we then arrive at Hausdorff measure and Hausdorff dimension, and briefly see how these ideas led to Fractal geometry and how it connects with Geometric measure theory.
